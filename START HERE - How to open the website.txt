MIDWEST IDENTITY SERVICES
Main website - how to open and review it
=========================================

1. Copy or unzip this whole folder onto your computer. Keep every folder
   together.

2. Open the folder and double-click "index.html".
   The homepage opens in your web browser (Chrome, Edge, Safari or Firefox).

3. Use the menu, buttons and links to move between pages, just as you would
   online.


Helpful tips
------------
- Do not move index.html (or any page folder) out of this folder. The pages
  need the "assets" folder that sits next to them.

- If double-clicking opens a text or code editor instead of a browser,
  right-click index.html, choose "Open with" and pick your web browser.

- Every "Book an Appointment" button opens your existing booking page:
  https://midwestidentityservices.com/book-an-appointment/
  That page is not part of this rebuild and keeps working exactly as it does
  now.

- The contact form on the Contact page needs a web server to actually send
  mail. While you are reviewing from this folder it will check the fields and
  then tell the visitor to call instead, rather than pretending it sent.

- Photos are temporary stock images. Replace them whenever you are ready; see
  "_developer/IMAGE REPLACEMENT GUIDE.txt".
